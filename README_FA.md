# آرتین خودرو — نسخه 1.0.4

این بسته یک پروژه پایه اندروید با Kotlin و Jetpack Compose است.
- حداقل اندروید: 7.0 (API 24)
- هدف ساخت: API 35
- خروجی CI: `app-debug.apk`
- گردش‌کار GitHub Actions: `Android APK Build`

## ساخت APK
1. کل محتویات این پوشه را در ریشه مخزن GitHub با نام `ARTINKHODRO` بارگذاری و commit کنید.
2. از زبانه Actions، گردش‌کار `Android APK Build` را اجرا کنید.
3. پس از موفقیت، artifact با نام `ARTIN-KHODRO-debug-apk` را دریافت کنید.
4. فایل `app-debug.apk` داخل artifact همان APK آزمایشی است.

## وضعیت
این نسخه، پوسته اولیه قابل ساخت و توسعه است؛ APK کامپایل‌شده در این بسته وجود ندارد و ساخت واقعی باید در GitHub Actions اجرا و نتیجه آن بررسی شود.
