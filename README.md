# ARTIN KHODRO — نسخه توسعه‌ای 1.1.2

اپلیکیشن بومی اندروید با Kotlin، Jetpack Compose و Room؛ رابط فارسی و راست‌چین.

## امکانات پیاده‌سازی‌شده در این بسته
- صفحه اصلی و ناوبری فارسی
- ثبت و جست‌وجوی پرونده خودرو
- سرفصل‌های آموزشی برق، انژکتور، سنسورها، ECU، مالتی‌پلکس CAN/LIN، ABS، گیربکس و خودروهای برقی
- جست‌وجوی کدهای خطای عمومی OBD-II و خانواده‌های ECU
- جست‌وجوی سراسری آفلاین در خودروها، کدهای خطا، ECU و کتابخانه فنی
- نرمال‌سازی حروف فارسی/عربی و ارقام فارسی در عبارت جست‌وجو
- پایگاه داده محلی Room برای خودروها، مستندات، DTC، ECU و سوابق تعمیر
- کتابخانه مستندات با وضعیت مجوز و اعتبارسنجی
- کاتالوگ آغازین برندها و مدل‌های منتخب بازار ایران
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی

## ساخت APK آزمایشی
در GitHub، محتوای همین بسته را مستقیماً در ریشه مخزن قرار دهید (نه پوشه والد ZIP). سپس از مسیر Actions، گردش‌کار `Build ARTIN KHODRO APK` را با گزینه `Run workflow` اجرا کنید. در صورت موفقیت، فایل `app-debug.apk` در بخش Artifacts با نام `ARTIN-KHODRO-debug-apk` قرار می‌گیرد.

پیش‌نیاز ساخت محلی: JDK 17، Gradle 8.9 و Android SDK Platform 35 و Build Tools 35.0.0. فایل `gradle-wrapper.jar` در این بسته نیست؛ برای ساخت محلی باید Gradle نصب‌شده در سیستم موجود باشد.

## وضعیت واقعی تحویل
- سورس پروژه: موجود
- بررسی ساختار ZIP: انجام شد
- بررسی ساختار XML و JSON: انجام شد
- کامپایل APK در این محیط: انجام نشده؛ Android SDK و Gradle نصب نیستند
- نصب روی گوشی واقعی: انجام نشده
- امضای انتشار: انجام نشده؛ این پروژه خروجی آزمایشی debug در نظر گرفته شده است

## محدودیت‌های مهم نسخه ناقص
این نسخه بانک اطلاعاتی کامل تعمیرگاهی نیست. پوشش خودروها محدود به کاتالوگ اولیه است و نقشه سیم‌کشی OEM، پین‌آوت سوکت‌ها، محل دقیق سنسورها، مقادیر مرجع، جعبه‌فیوز و رله و روش‌های تعمیر اختصاصی هنوز باید برای هر سال ساخت، تیپ، موتور، گیربکس و ECU با سند معتبر تکمیل و راستی‌آزمایی شوند. کدهای موجود عمومی OBD-II هستند و نباید به‌عنوان اطلاعات اختصاصی سازنده استفاده شوند.

بخش‌های ECU و مالتی‌پلکس فعلاً در سطح سرفصل و بانک آغازین قرار دارند؛ بانک عمیق تعمیر برد، توپولوژی شبکه و نقشه‌های اختصاصی در نسخه‌های بعدی تکمیل می‌شود.

## ایمنی و حقوق محتوا
اندازه‌گیری پایه‌ها، پروگرام، کالیبراسیون و تعمیر یونیت‌ها باید فقط با نقشه و دستورالعمل معتبر همان خودرو و رعایت نکات ایمنی انجام شود. فایل‌های دارای حق نشر فقط با مجوز به برنامه افزوده شوند.


## وضعیت ساخت

## Legacy wiring schema (v1.0.9)
The Room database now includes `wiring_diagrams`, `connector_pins`, and `network_nodes` for vehicle/trim-scoped wiring references, connector pinouts, and CAN/LIN topology. Migration 3→4 is included. Pin-level content must be transcribed from the exact matching source revision and reviewed before being marked verified.
